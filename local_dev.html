Sew Swap: local dev

React (Vite) frontend, Fastify API, Cloud Spanner emulator and Mailpit, all in Docker. The links below only work while the stack is running.

Start the stack

Run this from the repo root with Docker Desktop running.

docker compose up --build

If Docker can't find docker-credential-desktop, add its folder to your PATH first:

export PATH="/Applications/Docker.app/Contents/Resources/bin:$PATH"

Pages to open

WhatWhere
Web apphttp://localhost:5173
API health checkhttp://localhost:8080/api/health
Mailpit inbox (sign-in emails)http://localhost:8025
Spanner emulatorlocalhost:9010 (gRPC), localhost:9020 (REST)

On startup the API creates the Spanner instance and database and applies db/migrations/*.sql.

Sign in

  • Go to localhost:5173 and enter any email address. The first sign-in creates the account.
  • The sign-in email arrives in Mailpit. It has a button and a 6-digit code. Either one signs you in.
  • Each link or code works once and expires after 15 minutes. At most 5 emails per address per hour in production; compose allows 50 (LOGIN_REQUESTS_PER_HOUR).

Admins and roles

  • Emails in ADMIN_EMAILS become admins on sign-in. Locally the default is admin@example.test.
  • Admins open Manage user roles on the home page to grant or remove Admin and Swap Manager.

Google sign-in (optional)

  1. In the GCP console, go to APIs & Services → Credentials and create an OAuth client ID of type Web application.
  2. Add the authorized redirect URI http://localhost:5173/api/auth/google/callback.
  3. Put GOOGLE_CLIENT_ID=... and GOOGLE_CLIENT_SECRET=... in .env, then run the command below.
docker compose up -d api

The "Sign in with Google" button appears once both values are set. If a Google email matches an existing email-login user, it signs in to that account.

Useful commands

docker compose logs -f api
docker compose restart spanner api

Run this after changing anything in db/migrations/. Restarting only api keeps the old schema. The emulator keeps data in memory, so everything resets on restart.

docker compose down

Hot reload: apps/web/src and apps/api/src are bind-mounted. If you change a package.json, rebuild with docker compose up --build.

End-to-end tests

Playwright tests live in e2e/. Start the stack first, then run:

docker compose --profile test run --rm --build e2e

The HTML report is written to e2e/playwright-report/.

Production images

Each Dockerfile has a dev target (used by compose) and a prod target (for Cloud Run).

docker build --target prod -t sew-swap-api apps/api
docker build --target prod -t sew-swap-web apps/web

The web image proxies /api/* to $API_UPSTREAM, which must be set outside compose. In production, leave out SPANNER_EMULATOR_HOST, set APP_BASE_URL to the public https URL, and set AUTH_SECRET from Secret Manager.
